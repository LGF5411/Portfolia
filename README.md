# Портфолио Andrii Shnayder

Статический сайт без сборки: HTML, CSS, JS. Работает на GitHub Pages из корня репозитория.

## Что где
- `index.html` — главная: четыре проекта, каждый назван вопросом, на который отвечает.
- `work/lobby`, `work/bolt`, `work/tallink`, `work/minu-vahetus` — кейсы. `work/minu-vahetus/prototype/` — живой прототип.
- `about/` — обо мне. `404.html` — «не найдено».
- `assets/work/<проект>/` — картинки и видео. `assets/css/site.css`, `assets/js/site.js` — оформление и анимации.
- `tools/build.py` — все тексты страниц лежат здесь. Поменял текст → `python3 tools/build.py` → страницы пересобраны.
  Можно править и готовые `.html` руками, но следующая сборка их перезапишет.

## Почта
В `tools/build.py` впиши адрес в строку `EMAIL = ""` и пересобери: кнопка с почтой появится в подвале всех страниц.
