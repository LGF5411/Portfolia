# Портфолио Andrii Shnayder

Статический сайт: HTML, CSS, JS, без сборки. Открой `index.html`, чтобы посмотреть локально.

## Как устроено
- `index.html` — главная: портфолио как одно предложение, каждая часть ведёт на кейс.
- `work/bolt`, `work/organic-shop`, `work/restart`, `work/pulse` — кейсы.
- `about/` — обо мне, вопросы рекрутёра, контакты. `404.html` — страница «не найдено».
- `assets/js/site.js` — небо над Таллинном: цвета сайта меняются по настоящему положению солнца.

## Опубликовать на GitHub Pages
1. Создай репозиторий и загрузи в его корень **содержимое** этой папки (не саму папку).
2. Settings → Pages → Deploy from a branch → `main` / `(root)`.
3. Сайт откроется по адресу `https://ТВОЙ-НИК.github.io/ИМЯ-РЕПО/`.

## Что добавить перед отправкой рекрутёрам
**Скриншоты.** Пока картинки нет, на её месте видно, какой файл и какого размера положить:

| Проект | Файлы в `assets/work/…/` |
| --- | --- |
| bolt | `1.jpg` 2400×1350 · `bolt.jpg`, `food.jpg`, `driver.jpg` 1080×1920 |
| organic-shop | `1.jpg` 2400×1500 · `2.jpg`, `3.jpg` 1600×1000 · `banner.jpg` 1600×686 |
| restart | `1.jpg` 2400×1500 · `figma.jpg`, `site.jpg` 1600×1000 |
| pulse | `1.jpg` 2400×1500 · `assistant.jpg`, `optimizer.jpg` 1600×1000 |

Для превью на главной (при наведении на часть фразы) положи в папку каждого проекта `cover.jpg` 1600×1200.
Вместо картинки можно положить видео `.mp4`: поменяй расширение в `data-src` у нужного `<figure>`.

**Заглушки TK** в `about/index.html`: email и ссылка на CV (`cv.pdf` положи в корень сайта).

**Тексты кейсов** — черновики по тому, что ты рассказывал. Перепиши своими словами всё, что не сможешь объяснить на собеседовании.

## Проверить все состояния неба
Добавь к адресу `?sky=day`, `?sky=low`, `?sky=blue`, `?sky=dusk` или `?sky=night`.
Посетитель может закрепить светлую или тёмную тему кнопками «Light» внизу страницы.
